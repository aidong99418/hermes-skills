# DeerFlow 架构与Harness

## 起源
- ByteDance开源的深度搜索+生成框架
- 核心：多轮检索→推理→生成的循环pipeline
- 2025年发布，基于LangGraph实现

## 核心架构
```
用户查询
    ↓
Web搜索 (多源并行)
    ↓
文档解析 + 片段提取
    ↓
LLM推理链 (ReAct风格)
    ↓
再次搜索/深化
    ↓
综合生成答案
```

## Harness模式
- 将DeerFlow拆解为可组合的harness
- 每个节点可单独替换（搜索引擎/LLM/提示词）
- 支持自定义pipeline编排

## 与机器猫的关联
1. **外部fetcher借鉴**：多源并行+质量过滤的思路
2. **三层思考类比**：简单查询→单轮，复杂→多轮深化
3. **ReAct推理**：Agent执行-观察-推理循环模式

## 关键实现细节
- 使用BROWSE爬取+本地LLM解析
- 支持文件检索（本地知识增强）
- 评估指标：答案覆盖率+引用准确率
