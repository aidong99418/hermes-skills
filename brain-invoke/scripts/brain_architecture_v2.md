# 机器猫团队协作架构 v1.0

## 核心理念

**董哥的团队：**
- Hermes（主模型）= 团队Leader，最聪明，最终决策
- 本地模型（Ollama）= 团队成员，各有专长，执行任务
- Brain + Neural + RAG = 团队共享知识平台
- 目标：让本地模型变聪明，能被更好地安排，思考能力提升

## 三层思考架构

### 🔵 第1层：快速通道（不激活大脑）
**触发条件：** 简单、确定、我100%有把握的问题

**特征：**
- 有明确答案（查配置、读文件、执行已知命令）
- 单一工具调用
- 日常对话/问候
- 我能直接回答，不需要推理

**行为：** 直接回答，不检索brain

**例子：**
```
"现在几点了" → 直接回答
"帮我看一下磁盘" → df -h
"今天的报告在哪" → find
```

---

### 🟡 第2层：思考通道（激活大脑）
**触发条件：** 复杂、不确定、需要分析的问题

**触发关键词：**
```
思考/想一想/分析一下
区别是什么/原理是什么/怎么做到的
应该选哪个/哪个好/推荐
有没有问题/风险在哪
怎么优化/还有什么办法
不确定/拿不准/可能
```

**思考流程：**
```
1. 检索brain（本地知识库）
   → 有相关记录 → 引用 + 分析 + 回答
   → 无相关记录 → 进入步骤2

2. 检索RAG（rag_index）
   → 有相关知识 → 引用 + 分析 + 回答
   → 无相关记录 → 进入步骤3

3. 外部知识获取（按需）
   → 抓取相关资料 → 分析 → 验证 → 回答
   → 重要知识写进brain

4. 团队协作（高不确定性时）
   → 调用本地Ollama做专项分析
   → 汇总多个角度 → 给出最佳建议
```

**每次思考后：**
- 把有用的结论写进brain（知识沉淀）
- 更新neural connections（思维路径）
- 让本地模型学会这个知识

---

### 🔴 第3层：团队协作（高不确定/高风险）
**触发条件：** 重大决策、我没把握、涉及多领域

**触发关键词：**
```
架构设计/系统设计/整体方案
哪个方案更好/权衡/取舍
安全相关/权限/攻击
这个能实现吗/可行性
我没遇到过/新领域
```

**协作流程：**
```
1. 我（主模型）先分析问题，拆解子问题
2. 并行派发子问题给本地模型：
   - debugging类 → qwen2.5:7b（工具专家）
   - 推理分析类 → deepseek-r1:7b（推理专家）
   - 数据处理类 → qwen2.5:3b（打工仔）
   - 简单批量类 → smollm2:1.7b（快手）
3. 汇总各方分析 → 我做最终整合判断
4. 结论写进brain → 本地模型也学会
```

### 成长路径

2. **任务沉淀**：解决过的问题→写进scenarios→类似问题本地模型可参考
3. **模式固化**：成功的工具调用模式→写进tool_templates→本地模型模仿

## 判断我是否"拿不准"的自检

```
我拿不准吗？自检：
  ├─ 我有直接相关的记忆/知识吗？  → 有→直接答，无→拿不准
  ├─ 我最近遇到过类似问题吗？     → 有→参考，无→拿不准
  ├─ 我能100%确定这个方案对吗？   → 不能→拿不准
  ├─ 这个问题涉及多个领域吗？     → 是→团队协作
  └─ 这个错误我没见过吗？         → 是→思考+外部知识
```

## 重要原则

1. **不乱答**：拿不准就不答，说"我需要思考一下"
2. **不重复**：答案存进brain，避免下次重新想
3. **教团队**：每解决一个难问题，让本地模型也学到
4. **外部验证**：不确定的知识要查证，不瞎编
5. **渐进增强**：每次思考都让系统变聪明一点
