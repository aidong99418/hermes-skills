# MCP Servers 合集

官方参考实现，共7个MCP Server（Python SDK版）：

| Server | 功能 | 用途 |
|--------|------|------|
| filesystem | 安全文件读写 | 读取NAS文件、搜索内容 |
| git | Git仓库操作 | 读仓库历史、搜索代码 |
| memory | 知识图谱记忆 | 持久化记忆、跨会话 |
| sequentialthinking | 反思式推理 | 复杂问题分步思考 |
| fetch | 网页内容获取 | 抓取URL转Markdown |
| time | 时间时区转换 | 处理时间相关任务 |
| everything | 全功能测试 | 参考实现 |

安装：pip install mcp
使用：参考各子目录README
