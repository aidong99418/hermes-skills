## 一、WPS表格（Spreadsheets）

### 核心函数速查

| 函数 | 语法 | 用途 |
|------|------|------|
| SUM | `=SUM(A1:A10)` | 求和 |
| VLOOKUP | `=VLOOKUP(查找值, 区域, 列号, FALSE)` | 精确查找（FALSE=降序不要求） |
| HLOOKUP | `=HLOOKUP(查找值, 区域, 行号, FALSE)` | 横向查找 |
| IF | `=IF(条件, 真值, 假值)` | 条件判断 |
| SUMIF | `=SUMIF(范围, 条件, 求和范围)` | 条件求和 |
| COUNTIF | `=COUNTIF(范围, 条件)` | 条件计数 |
| AVERAGE | `=AVERAGE(A1:A10)` | 平均值 |
| MAX/MIN | `=MAX(A1:A10)` / `=MIN(A1:A10)` | 最大/最小值 |
| CONCATENATE | `=CONCATENATE(A1,B1)` 或 `=A1&B2` | 文本合并 |
| LEFT/RIGHT/MID | `=LEFT(文本, 字符数)` | 文本截取 |

### 常用快捷操作

- **批量填充**：选中区域 → 输入公式 → Ctrl+Enter
- **冻结窗格**：「视图」→「冻结窗格」→ 选择冻结行/列
- **筛选**：「数据」→「自动筛选」，或 Ctrl+Shift+L
- **删除重复项**：「数据」→「删除重复项」
- **数据分列**：「数据」→「分列」→ 选择分隔符（逗号/空格/Tab）
- **条件格式**：「格式」→「条件格式」→ 设置规则高亮

### 常见错误处理

- **#DIV/0!**：除数为0 → 检查分母是否有0或空值
- **#N/A**：查找值不存在 → VLOOKUP找不到结果，用IFERROR包裹
  - 正确写法：`=IFERROR(VLOOKUP(...), "未找到")`
- **#REF!**：`=VLOOKUP(..., 5, FALSE)` 列号超出区域 → 减少列号
- **#VALUE!**：数据类型不匹配 → SUM不能对文本求和，清理数据
- **循环引用**：公式直接或间接引用自身 → 改公式结构

### 打印控制

- **打印区域**：「页面布局」→「打印区域」→「设置打印区域」
- **分页预览**：「视图」→「分页预览」，拖动蓝线调整分页
- **缩放打印**：「页面布局」→「纸张大小/缩放」，设为1页宽
